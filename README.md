# Personal Website

This is the repository for my personal website, hosted on [Neocities](https://neocities.org/). It's a static site built primarily with HTML and CSS.

The site is an evolving space where I share information about myself, my work, and things I'm interested in. It’s a personal project intended to grow over time.

## What You'll Find

The content of the site may change, but generally includes or will include:

- A resume and background information
- A portfolio of personal or professional projects
- Notes on what I’m currently reading or watching
- Pages or links to experiments, writing, or other side interests
